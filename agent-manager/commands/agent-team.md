description: 按依赖拆解任务、协调多个智能体并行执行并验证结果
argument-hint: "<要执行的任务描述>"
---

任务：$ARGUMENTS

读取并遵循 `agent-team` 技能（`../skills/agent-team/SKILL.md`）：

1. 若任务描述为空，请用户提供目标，不派发空任务。
2. 盘点运行时可用 agent 和工具，建立含依赖、读写范围、验收条件的任务表。
3. 独立任务按容量分批并行，同一文件只允许一个写入者，依赖验收后再启动下游。
4. 记录任务状态，失败先确认旧任务停止，再重试或接管。
5. 核对实际变更与验证证据，汇总完成项、风险及阻塞；不把未完成任务报告为成功。

完整规则以技能为准；此命令只提供快捷入口。
